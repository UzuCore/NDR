# NDR r193 — 동일 압축파일 내부 복사·이동 구현 및 편집 안전성 보강

일자: 2026-11-01 / 대상: Rust NDR, Windows x64, 배포 동봉 7zip+.

## 확인된 미구현 기능

두 패널에 **같은 ZIP/7z/TAR의 서로 다른 내부 폴더**를 열었을 때 Ctrl+C/Ctrl+V 또는 Ctrl+X/Ctrl+V를 사용할 수 없었다. `src/ui/archive_edit.rs`가 동일한 아카이브를 무조건 거부했고, `src/ui/commands.rs`에는 F4를 별도로 차단하는 중복 검사가 있었다.

### 변경

동일 파일이라도 **서로 다른 내부 경로**로 복사·이동할 수 있게 했다. 기존 구조대로 작업 전 읽기 전용 형식을 검사하고, 원본에서 임시 작업 폴더로 선택 항목을 추출한 다음, 압축파일의 별도 변경용 복사본에서 새 항목을 추가한다. 이동은 추가 성공 후에만 원본 항목을 삭제한다.

`archive::validate_same_archive_transfer()`는 작업 시작 전에 다음을 차단한다.

- 출발 경로와 목표 경로가 같은 경우 (동일 파일 덮어쓰기 후 원본 삭제로 인한 손실)
- 선택한 폴더 자체/그 하위 폴더로 복사·이동하는 경우
- 새 목표가 선택한 다른 원본이거나 그 조상·자손인 경우
- 이름이 같은 여러 원본이 같은 목표 이름으로 충돌하는 경우
- `..` 경로 또는 비정상 키

목표 아카이브 패널에 저장된 암호가 없으면 같은 파일을 읽은 출발 패널의 암호를 사용한다. 출발/목표가 서로 다른 파일인 경우에는 기존 암호 정책을 유지한다.

### 자동화 검수

실제 테스트용 ZIP 파일에 `a.txt`, `folder1/nested.txt`, `receive/existing.txt`를 만들고 동일 ZIP을 두 패널에 서로 다른 경로로 열었다. `src/ui/shortcut_tests.rs`에서 **Ctrl+C/Ctrl+V 복사**, **Ctrl+X/Ctrl+V 이동**, **F4 이동** 및 자기 경로/하위 경로 차단을 검사한다. 기존 목적지 항목을 보존하고, 이동 때에만 출발 파일을 삭제하며, 완료된 Ctrl+X는 클립보드를 정리한다. 순수 검증 함수 테스트는 `src/archive.rs`의 `same_archive_copy_move_rejects_self_overlap_and_duplicate_destinations`에 포함했다.

## 실물 7zip+에서 재현한 이름 변경 오류

동봉 `7zip+`에서 `7z rn pack.zip missing.txt new.txt`는 **실제로 변경한 항목이 없어도 종료 코드 0, `Everything is Ok`**를 반환했다. NDR이 종료 코드만 검사하면 존재하지 않는 항목의 이름 변경을 성공으로 판단할 수 있었다. 삭제에서도 같은 종류의 오판이 없도록 보강했다.

### 변경

- `archive::rename_entry`가 `rename_entries` 기반 검증을 사용한다. 파일/폴더 존재를 변경 전 검사하며, 7zip+ 명령 이후 새 이름 존재·예전 이름 부재를 확인한다. 대소문자만 바뀌는 이름 변경도 실제 표기를 확인한다.
- `archive::delete_entries`가 삭제 전 대상의 실제 존재 여부를 확인하고, 명령 이후 대상이 사라졌는지를 목록으로 확인한다. 실제 파일이 없거나 `7zip+`가 아무것도 삭제하지 않은 작업을 성공으로 처리하지 않는다.
- GUI의 여러 항목 이름 변경은 `rename_entry`를 여러 번 커밋하는 대신 `rename_entries`의 **단일 변경용 복사본**에 순서대로 적용하고 모두 성공했을 때만 원본 ZIP/7z/TAR에 반영한다. 뒤쪽 실패 시 원본이 부분 변경되는 버그를 방지한다.
- 복수 이름 변경에서 중복 출발 이름·중복 목표 이름·기존 항목과의 충돌·폴더 자기 하위로의 변경을 변경 전에 차단한다.

### 검증 및 안전성

`src/archive.rs`의 `real_zip_7z_tar_rename_and_delete_check_updates_and_preserve_originals`는 ZIP/7z/TAR 실물 아카이브 각각에 다음을 적용한다.

1. 존재하지 않는 항목의 삭제와 이름 변경 거부 및 원본 바이트 유지
2. 두 항목을 같은 이름으로 변경하는 충돌 거부
3. 첫 번째 임시 변경 후 **고의로 오류를 발생**시켜 원본 바이트 단위 롤백 확인
4. 정상 2개 항목의 일괄 이름 변경과 특정 항목만 삭제해 나머지가 유지됨을 확인

모든 수정은 다운로드 폴더와 무관한 격리된 테스트용 압축파일만 사용한다. RAR·ZIPX·ISO 등 기존 읽기 전용 아카이브는 여전히 내부 편집을 지원하지 않는다.

## 검수 범위의 구분

자동화는 실제 ZIP/7z/TAR를 대상으로 실행하는 **Rust 핵심 기능과 GUI 키 입력 경로 테스트**다. 임의의 외부 프로그램에서 발생하는 클립보드 충돌, 장치 제거, 불안정한 네트워크, 모든 76개 등록 확장자에서의 쓰기 기능까지 검수 완료한 것은 아니다. 이전 r192의 실제 PS3 ISO, r191의 웹 아카이브 59개에 대한 검수도 전체 회귀 테스트에 포함한다.
