# NDR 기능 공백 검수 · 2026-11-01 (r187 기준 → r188 작업)

이번 검수는 원본 실행파일의 재분석이 아니라 현재 Rust 소스의 실제 명령 연결, 플랫폼별 분기, 명시적 기능 제한, 테스트 실행 경로를 대상으로 한다. `cargo test` 통과가 모든 실사용 환경의 보증은 아니다.

## 이번 작업에서 구현한 항목

| 기능 | 이전 상태 | r188에서 변경한 내용 |
|---|---|---|
| `Ctrl+H` 파일 검색 | 원본 단축키가 실제 `search` 명령 대신 소비됨 | 검색 창으로 연결 |
| `Ctrl+Shift+A` 이동 압축 | 단축키가 실제 `archiveMove` 대신 소비됨 | 압축 설정 창으로 연결 |
| 압축파일 설치 명령 | 키를 소비하며 `miArcInstall`의 명령 매핑도 없음 | 설치 명령 매핑 복구. 단축키 편집기에서 별도로 지정한 키로 실행 가능 |
| FTP/SFTP 패널로 `Ctrl+V` | 파일 클립보드 붙여넣기 경로가 FTP 업로드와 연결되지 않음 | 로컬 파일·폴더 또는 ZIP에서 추출한 클립보드 항목을 FTP 전송 작업으로 업로드 |
| FTP/SFTP로 `Ctrl+X` → `Ctrl+V` | 이동 요청이 무시되거나 로컬 경로를 대상으로 처리됨 | 성공적으로 업로드되었고 충돌 건너뛰기가 없는 항목만 원본에서 제거. 실패·중단 시 원본 유지 |
| 오래된 내부 클립보드 | 외부 앱이 새 텍스트 등을 복사한 뒤에도 NDR의 예전 파일 경로로 붙여넣기 가능 | Windows 클립보드 변경 번호 비교로 오래된 내부 복사 항목 무효화 |
| 클립보드 회귀 테스트 | 사용자 OS 클립보드를 직접 읽어 테스트 오염 가능 | 주입 가능한 파일 클립보드 판독 함수로 격리 |

기본 `Ctrl+I`는 `miFilterCustom`과 `miArcInstall`이 모두 사용한 충돌 키이므로 기존 필터 단축키를 빼앗지 않는다. 설치 명령은 **단축키 편집기로 충돌하지 않는 키를 지정**한 경우 활성화되며, Windows에서 해당 파일 형식에 `install` 셸 동작이 등록되어 있어야 실제 설치가 실행된다.

## 실제로 확인한 잔여 제한 기능

| 우선순위 | 기능 | 확인 지점 | 상태 |
|---|---|---|---|
| 높음 | ZIP/7z 등의 압축파일 내부에서 하위 폴더 전체 **파일 이름 검색** | `src/ui/search_dialog.rs`, `search_command` | 압축파일에서는 의도적으로 차단되어 있어 추가 구현 필요 |
| 높음 | FTP/SFTP 원격 파일 선택 후 `Ctrl+C` / `Ctrl+X`로 클립보드에 가져오기 | `src/ui/ftp_pane.rs`, `ftp_allows` | FTP 패널의 원격 항목 클립보드 복사 경로 없음 (FTP로의 붙여넣기와 별개) |
| 보통 | 압축파일/FTP 패널 내부 **고급 일괄 이름 변경** | `src/ui/rename_dialog.rs`, `advanced_rename` | 해당 위치에서는 기능 차단. 새 원격·압축 편집 워크플로 필요 |
| 보통 | 양쪽 패널에서 **동일한 압축파일**을 열어 항목 복사·이동 | `src/ui/archive_edit.rs`, `archive_transfer_out_location` | 데이터 손상 방지를 위해 명시적으로 거부. 원자적 아카이브 내 이동 구현 필요 |
| 보통 | 클립보드용 대용량 압축 임시 추출 파일의 장기 보관·청소 | `src/ui/archive_edit.rs` | 외부 프로그램 붙여넣기 유효성 때문에 임시 파일이 프로세스 수명 이후 남을 수 있어 별도 수명 관리 필요 |

위 표는 **코드에서 명시적으로 재현 가능하거나 제한된 항목**의 목록이며, UI 전 기능의 누락이 0건이라는 뜻은 아니다. FTP/SFTP 서버 종류별 실전 연결, 암호화 압축파일의 다양한 암호 체계, 대용량 전송/취소는 별도의 실기기·실서버 검수가 필요하다.
