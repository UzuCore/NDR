# NDR r189 — 압축 포맷 및 클립보드 UI 검수

검수 환경: Windows x64, NDR Rust, 실제 배포되는 `Resources/Tools/7zip/Full/7z.exe` 및 `7z.dll` (7zip+ 26.05, 2026-10-21).

## 전체 형식 분류

- NDR가 압축/이미지로 인식하는 **76개 명시적 확장자**를 `archive_format`과 `bundled_can_browse`로 모두 분류·검사한다.
- 엔진의 `7z i` 형식 목록에 실제 핸들러가 없는 **`.ace`, `.tar.lz`, `.tlz`, `.uefi`**는 파일 선택 시 목록으로 진입하거나 추출 대상으로 진행하지 않도록 차단한다. **Lzip**은 LZMA 파일과 이름이 비슷하지만 별개 형식이므로 LZMA 지원으로 간주하지 않는다. `uefif`와 `scap`이 있다고 `.uefi`를 지원한다고 가정하지 않는다.
- 나머지 확장자는 엔진의 목록/추출 시도로 연결한다. **확장자가 허용된다고 그 파일의 내용·압축 방식까지 항상 읽을 수 있다는 뜻은 아니다.** 구체적인 파일의 7-Zip 목록/해제에 실패하면 오류를 알리고 출력은 커밋하지 않는다. 암호화 방식, 복구 불가 분할 볼륨, 특이한 ZIPX 압축 방식은 개별 파일 검증이 필요하다.
- **추출 중인 작업은 취소·실패 시 안전한 스테이징 경로로 격리하고, 읽을 수 없는 형식은 목적지 폴더를 만들기 전에 거부한다.** 지원하지 않는 형식을 여러 파일 중 하나라도 선택했다면 작업 전체를 시작하지 않는다.
- **TAR.BZ2 실제 테스트에서 목록 판독 오류를 발견해 수정**했다. 7zip+가 BZip2 스트림에 `Path` 값을 내보내지 않고 `Size =`도 빈 값으로 반환하므로, 실제 추출 가능한 스트림의 **한 개 멤버 이름을 확장자에 따라 복원**하고 크기를 알 수 없는 것으로 취급한다. 크기가 없는 항목에 `0바이트` 검증을 강제하지 않되, 경로 안전 검증과 스테이징 추출 검증은 유지한다. `.tbz`·`.tbz2` 별칭도 테스트한다.

## 실제 압축파일 테스트 범위

| 포맷 | 실제 파일 생성/목록 조회/추출 | 내부 수정 | 비고 |
|---|---|---|---|
| ZIP, 7z, TAR | 모두 테스트 | 가능 | 7zip+의 추가·삭제 작업 검사 |
| TAR.GZ, TAR.BZ2 | 모두 테스트 | 불가 | BZip2 목록은 파일명·원본 크기가 빠져 있어 NDR에서 안전하게 단일 스트림으로 복원 |
| ALZ, EGG | 모두 테스트 | 불가 | 번들 7zip+의 읽기/추출을 활용; GUI 생성 옵션은 표시하지 않음 |
| WIM | 모두 테스트 | **불가** | 목록/추출/생성 가능하지만 실제 `7z d`가 오류 코드 2로 실패하므로 편집을 차단 |
| ZIPX | 실제 ZIP 컨테이너를 ZIPX 확장자로 복제하여 조회 | 불가 | ZIPX 전용 압축 방식 전체를 검증했다는 뜻은 아님 |
| GZIP, BZIP2, XZ | 별도 7zip+ CLI 테스트에서 생성/목록/검사 통과 | 불가 | 단일 스트림; 전체 TAR 멤버 목록이 직접 나오지는 않음 |
| RAR, ARJ, ISO, CAB 및 디스크 이미지 등 | 7zip+ `i` 핸들러 존재 여부를 근거로 분류 | 불가 | 별도의 실제 정상 파일을 모두 확보한 것은 아니므로 파일별 성공 보장은 아님 |
| ACE, TAR.LZ, TLZ, UEFI | **차단 테스트** | 불가 | 엔진 핸들러 없음; 작업 시작 전 설명 표시 |
| ZSTD 등 | 7zip+에 목록/읽기 핸들러 존재 | 불가 | 도구의 `-tzstd` 생성은 실패하므로 생성 가능한 형식으로 제시하지 않음 |

## Ctrl+C/X 시각적 진행 경험

- 빠르게 끝나는 작업에서는 기존의 커다란 **"작업 준비 중" 창이 깜빡이지 않도록 180ms 지연**하고, 완료 알림만 보여준다.
- 오래 걸리는 압축 내부 항목 준비는 작고 중앙에 정렬된 창으로 표시한다. 압축항목 이름과 **실제 추출한 항목 수/전체 항목 수, 진행 바, 취소 버튼**을 제공한다. 비밀번호 확인과 실패를 기존 절차로 처리한다.
- 완료 시 별도 확인 버튼이 없는 **약 1.1초의 알림**을 표시한 뒤 자동으로 닫는다. 잘라내기는 붙여넣기 성공 전 원본을 삭제하지 않는다.
- 진행률은 **항목 수 기반**이며 단일 대용량 파일을 추출하는 중에는 항목이 끝날 때까지 활동 표시가 이어질 수 있다. 압축 엔진의 바이트 단위 내부 진행률까지 표시하는 것은 별도 개선 사항이다.

## 테스트 조건과 한계

- 포맷별 생성/목록/추출 테스트와 모든 등록 확장자 허용 판정 테스트는 임시 디렉터리에서 실행하며 끝나면 정리한다.
- 단축키로 지원되지 않는 형식을 열거나 추출하려는 경우 대화창·업무 시작 여부를 검사한다.
- 실제 비표준 RAR·ACE·ZIPX·ZSTD·디스크 이미지의 모든 변종 샘플과 손상/암호화 상황을 전부 확보해 검증한 것은 아니므로, 원본을 지우는 작업은 항상 버전별 수정 허용 형식에 한해 진행한다.
