# NDR r194 — bk3.7z 실물 압축파일의 패널 오류·진입 후 복귀 불가 수정

검수일: 2026-11-01 / Windows x64 / 번들 7zip+ 26.05.

## 실제 재현

사용자 Downloads 폴더의 `bk3.7z`는 4,013,735바이트의 **정상 7z** 파일이다. `7z l -slt -ba`와 `7z t` 모두 종료 코드 0을 반환하고 파일 125개, 폴더 15개를 보고했다. 명령행 결과의 마지막에는 `Path = nul`, `Attributes = A`, `Size = 0`인 항목이 있다.

Windows의 `NUL`은 예약 장치명으로, 일반 파일 경로처럼 열거나 추출하면 안 된다. 기존 `src/archive.rs::parse_listing()`은 이 항목을 `validate_key()`에서 거부하고 압축파일 **전체 목록 조회를 실패**로 처리했다. `src/ui/mod.rs::apply_listing()`의 이전 동작은 이 실패를 패널 상단에 빨간색 오류로만 남기고 `archive` 상태를 유지했으므로, 사용자는 패널에 갇힌 듯한 상태를 경험했다.

## 수정 원칙

1. **정상 항목의 탐색 허용:** Windows 예약 장치명만 화면용 목록에서 건너뛰되, 그 수를 상태 표시줄에 설명한다. `../` 경로, 심볼릭 링크, 리파스, 중복 이름, 그 밖의 안전하지 않은 경로의 기존 강력한 거부 정책은 그대로 유지한다. 별도의 엄격한 목록 파서는 회귀 테스트용으로 보존한다.
2. **선택 파일 복사·추출:** 유효한 이름만 추출하도록 한다. 단일 항목 열기/미리보기에서 `validate_key` 전체를 적용하여 `nul`을 파일 시스템에 전달하지 않는다.
3. **전체 추출:** 번들 7zip+ 호출에 `-spd` 및 검출된 예약 항목에 대한 `-x!<name>` 제외 옵션을 추가한다. 실제 압축파일을 대상으로 `7z x -spd -x!nul`를 실행해 **파일 124개·폴더 15개를 모두 추출**했고 위험한 이름은 만들지 않았다. 나머지 전체 파일의 합계 60,789,073바이트는 원본 테스트 결과와 일치한다.
4. **압축파일 내부 편집:** 읽기와 추출은 가능하지만, Windows에서 이름을 표현할 수 없는 항목이 포함된 원본 아카이브에는 **추가·삭제·이름 변경을 거부**한다. 파일을 수정하면서 숨겨진 `nul` 항목을 조용히 유실시키는 경우를 방지한다.
5. **오류 복구:** 다른 오류로 실제 목록 조회가 실패하면 자동으로 압축파일의 상위 폴더로 돌아오고 실패한 파일에 커서를 맞춘다. 사용자가 재실행하거나 다른 패널로 이동하지 않아도 된다. 원인 메시지는 상태 표시줄에 유지한다.

## 회귀 테스트

- `src/archive.rs`: Windows 예약 장치명만 탐색 목록에서 제외, 나머지 잘못된 경로/링크/중복 이름은 차단하는 단위 테스트.
- `src/ui/shortcut_tests.rs`: 열 수 없는 `.7z`로 패널에 진입했다가 안전하게 돌아오는 테스트, 실제 `bk3.7z` 복사본을 양쪽 패널 중 하나에서 열고 하위 폴더에 진입한 뒤 상위 폴더 및 파일 위치까지 복귀하는 UI 경로 테스트.
- `src/ui/tools_tests.rs`: 이전 테스트는 손상된 가짜 ISO·ALZ·EGG를 판별 없이 `archive` 상태에 유지하는 것을 성공으로 간주했다. **가짜 ISO의 실패 시 자동 복귀**와 실제로 생성한 **정상 ALZ·EGG의 패널 진입·파일 표시**를 검증하도록 수정했다.
- `tests/archive_local_bk3.rs`: 환경변수 `NDR_LOCAL_BK3`에 있는 실제 다운로드 ISO가 아닌 **7z 원본**을 바꾸지 않고, 내부 항목 139개 탐색, 장치명 1개 제외, 선택 파일 복사, 전체 124개 파일 안전 추출, 유해 이름 열기 차단, 읽기/편집 거부 정책, 원본 SHA-256 전후 일치 검증. 전체 추출은 별도 격리 폴더에서만 이루어지고 완료 시 정리한다.
- 전 버전의 ZIP·7z·TAR 복사·이동·삭제, PS3 ISO 2개, 웹 압축파일 59개 회귀 검수 유지.

복구 시에도 원본 `bk3.7z`를 수정·이동·삭제하지 않는다. 사용자 개인 파일은 Git 저장소나 배포 ZIP에 포함하지 않으며, 실제 검수 상세 결과는 로컬 `target/bk3-qa/ndr-bk3-results.json`에 보관한다.

## 범위

이 검수는 앞서 누락된 특정 실물 샘플 및 그 실패 유형을 해결하기 위한 것이다. 등록된 모든 확장자의 무작위 실물 조합, 모든 압축 알고리즘, 모든 UI 조작의 전수 테스트가 끝났다는 뜻은 아니다.
